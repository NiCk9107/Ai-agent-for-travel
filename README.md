# О!дин запрос (Трек 01)

AI-агент, который превращает размытое желание («хочу к тёплому морю в ноябре с ребёнком»)
в собранную поездку: направление → отель → перелёт → трансфер → проверка состыковок →
корзина → оформление. Всё в одном диалоге.

- **Видео-скринкаст:** ССЫЛКА_НА_ВИДЕО
- **Развёрнутый сервис:** https://kryliy-front.onrender.com
  (бесплатный хостинг — первый ответ после простоя может идти до минуты)

## Быстрый старт

```bash
git clone https://github.com/ostrovok-hackathon-2026/kryliy.git
cd kryliy
cp .env.example .env      # вставьте LLM_API_KEY (см. ниже)
docker compose up --build
# открыть http://localhost:8080
```

Первая сборка — 3–6 минут. Готово, когда в логе появится `Application startup complete`.

## Зависимости и переменные окружения

**Ресурсы:** 1 CPU, 1 GB RAM. Внешних сервисов нет — база SQLite внутри контейнера.
**Нужен ключ** к любому OpenAI-совместимому LLM API; модель должна поддерживать tools (function calling).

> ⚠️ **Gemini API напрямую недоступен из РФ** — ответ `400 User location is not supported`.
> Используйте **OpenRouter** (значения по умолчанию в `.env.example`): он работает из РФ
> и даёт доступ к Gemini, GPT, Llama и другим моделям. Ключ: https://openrouter.ai/settings/keys
> Бесплатные модели (`:free`) ограничены 50 запросами в день — для полной проверки


| Переменная | По умолчанию | Описание |
|---|---|---|
| `LLM_API_KEY` | — (**обязательно**) | Ключ LLM API |
| `LLM_BASE_URL` | `https://openrouter.ai/api/v1` | Адрес OpenAI-совместимого API |
| `LLM_MODEL` | `openai/gpt-4o-mini` | Основная модель |
| `LLM_FALLBACK_MODEL` | пусто | Запасная модель, если основная недоступна |
| `ALLOWED_ORIGINS` | пусто | Доп. адреса фронта для CORS (через запятую) |

Примеры `.env`:

```bash
# OpenRouter — работает из РФ
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_API_KEY=sk-or-v1-...
LLM_MODEL=nvidia/nemotron-3.5-super-vl:free
LLM_FALLBACK_MODEL=recursive/flint-v1.0:free

# Gemini напрямую — только не из РФ (так работает развёрнутый сервис)
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
LLM_API_KEY=...
LLM_MODEL=gemini-3.5-flash-lite
LLM_FALLBACK_MODEL=gemini-3.8-flash
```

### Что попробовать

1. «Хотим к тёплому морю в ноябре, двое взрослых и ребёнок 5 лет, до 200 тысяч»
2. Выберите направление, отель («Сравни первые два» — покажет таблицу), рейсы и трансфер
3. Посмотрите таймлайн: валидатор подсветит проблемы (например, долгое ожидание заселения)
4. Напишите «А давай на два дня позже» — план пересоберётся, появится плашка «Что изменилось»
5. «Подтверждаю, оформляй» — номер заказа (оплата — мок)

## Что умеет

- **Понимает размытые запросы.** «Недорого», «с малышом», «без долгих перелётов» → конкретные условия поиска.
- **Не засыпает вопросами.** Обязательно только откуда, когда и кто едет; остальное агент
  додумывает сам и пишет, какие допущения сделал. Не больше двух уточнений.
- **Подбирает и объясняет.** 3 направления с погодой, 3 отеля с плюсами, компромиссами и рисками,
  рейсы, трансфер, таблица сравнения.
- **Проверяет состыковки.** Прилёт → трансфер → заселение, выезд → вылет, вместимость номера,
  животные, бюджет.
- **Пересобирает план, а не начинает заново.** Меняются только затронутые части, показывается разница в цене.
- **Показывает ход работы.** Статусы в реальном времени: «Ищу отели…», «Проверяю состыковки…».

## Главный принцип: LLM думает — код считает

| Модель (LLM) | Код |
|---|---|
| Понимает запрос, ведёт диалог | Ищет отели, рейсы, трансферы |
| Решает, какой инструмент вызвать | Считает цены, ночи, итог корзины |
| Объясняет выбор человеческим языком | Ранжирует отели (`logic/scoring.py`) |
| | Проверяет даты и время (`logic/validator.py`) |
| | Пересобирает план по графу зависимостей (`agent/replan.py`) |
| | Строит карточки и обрабатывает кнопки — модель не может показать отель, которого нет в данных |

```
Браузер ── http://localhost:8080 ──► один контейнер
                                      ├── /            собранный фронт (React + Vite)
                                      └── /api/...     FastAPI
                                            ├── agent/   цикл агента, инструменты, промпт, пересборка
                                            ├── logic/   ранжирование и проверка состыковок
                                            ├── tools/   направления, отели, рейсы, трансферы, погода
                                            └── db/      SQLite: каталог, сессии, история, кеш API
                                                 │
                                                 ▼
                                      LLM: любой OpenAI-совместимый API
```

## Данные: что реальное, а что нет

| Данные | Источник |
|---|---|
| Погода по месяцам | ✅ Open-Meteo |
| Отели: названия и координаты | ✅ OpenStreetMap (Overpass API) |
| Время и расстояние трансфера | ✅ OSRM |
| Цены и детали отелей, номера, отзывы | 🔸 синтетика, правдоподобная по звёздам и району |
| Рейсы | 🔸 синтетика, повторяемая (одинаковый запрос → одинаковые рейсы) |
| Наличие мест, оплата |  мок |

Чтобы подключить реальный API Островка, достаточно заменить `backend/tools/hotels.py` —
сигнатура функции та же; агент, проверки и интерфейс не меняются.

## Тесты

- **31 юнит-тест** (`backend/tests`): ранжирование, проверка состыковок, сценарии пересборки.
- **Автопрогон сценариев** (`backend/scripts/run_eval.py`): скрипт ведёт диалог за пользователя
  до оформления заказа и проверяет нарушения. Отчёты — в [`eval/`](eval/).

```bash
cd backend
pip install -r requirements-dev.txt

```

## Для разработки (без Docker)

```bash
# бэкенд
cd backend
python -m venv .venv
.venv\Scripts\activate            # macOS/Linux: source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env              # и вставить ключ
uvicorn main:app --reload         # http://localhost:8000

# фронт (во втором терминале)
cd frontend
npm install
npm run dev                       # http://localhost:5173, VITE_API_URL=http://localhost:8000
```

## API

| Метод | Путь | Что делает |
| `POST` | `/api/session` | Новая сессия → `{session_id}` |
| `POST` | `/api/chat` | Сообщение или нажатие кнопки → ответ агента, карточки, состояние поездки |
| `POST` | `/api/chat/stream` | То же через SSE: события `status`, `reply`, `error`, `done` |
| `GET` | `/api/state/{session_id}` | Текущее состояние поездки |
| `GET` | `/api/cart/{session_id}` | Корзина |
| `POST` | `/api/checkout` | Оформление (мок оплаты) |
| `POST` | `/api/reset` | Начать заново |
